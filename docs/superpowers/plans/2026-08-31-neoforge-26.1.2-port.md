# NeoForge 26.1.2 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a feature-equivalent Minecraft 26.1.2 NeoForge JAR for ATM11 while preserving the existing builds.

**Architecture:** Create an independent `neoforge-26.1.2` Gradle project seeded from the modern source tree. Port one API boundary at a time, keeping server/domain code intact where it does not depend on Minecraft APIs.

**Tech Stack:** Java 25, Gradle 9.2.1, ModDevGradle 2.x, NeoForge 26.1.2.x, JUnit 5, NeoForge GameTest.

**Spec:** `docs/superpowers/specs/2026-08-31-neoforge-26.1.2-port-design.md`

## Global Constraints

- Do not modify or delete the 1.21.1 or 1.12.2 implementations.
- Keep mod version `0.2.8` and displayed author `HooDoo`.
- Preserve all standalone features; URL media downloading remains disabled.
- Archive successful builds as `releases/customjukeboxdiscs-26.1.2-0.2.8.jar`.
- Commit each independently verified task.
