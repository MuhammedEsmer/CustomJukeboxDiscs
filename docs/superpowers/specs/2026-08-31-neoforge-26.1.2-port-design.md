# NeoForge 26.1.2 Port Design

## Goal

Add a standalone Minecraft 26.1.2 NeoForge build of Custom Jukebox Discs for ATM11 without changing or removing the existing Minecraft 1.21.1 NeoForge and 1.12.2 Forge builds.

## Structure

The new build lives in `neoforge-26.1.2/`. It owns its Gradle wrapper, build configuration, source tree, tests, and generated resources. Shared assets begin as a copy of the current 1.21.1 version so each published version remains reproducible and can evolve independently.

## Compatibility target

- Minecraft: `26.1.2`
- Loader: NeoForge `26.1.2.x`, pinned to the build used by the current ATM11 release after its instance manifest is available
- Java: `25`
- Gradle: `9.1+`
- Mod version: `0.2.8`
- Author shown to users: `HooDoo`

## Feature scope

The port retains custom MP3/OGG uploads, vanilla jukebox playback, positional audio, the playback preference toggle, the Disc Writer, the Disc Rack, random disc variants, recipes, creative tab, server access controls, client cache, My Uploads, and Server Library. URL-based media downloading remains excluded.

Sophisticated Backpacks support is compiled only if compatible 26.1.2 artifacts exist. Its absence must not block the standalone mod or ATM11 testing; compatibility is restored as a separate adapter when the dependency is available.

## Migration strategy

Start from the working 1.21.1 implementation, replace build metadata with the official 26.1.2 toolchain, then migrate registrations, data components, networking, menus, rendering, audio, recipes, and tests in compiler-guided slices. No compatibility shims are added to the older projects.

## Release behavior

`build` must copy `customjukeboxdiscs-26.1.2-0.2.8.jar` into the repository-level `releases/` directory without deleting older artifacts.

## Verification

The port is complete only when unit tests pass, the production JAR builds, metadata inside the JAR reports Minecraft 26.1.2 / version 0.2.8 / author HooDoo, and the JAR starts in the downloaded ATM11 client. GameTests are run when the 26.1.2 test harness is operational.
