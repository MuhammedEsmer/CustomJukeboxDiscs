# 0.2.7

Covers everything since 0.2.5. If you run a server, this update matters: writing discs did not work
on a dedicated server before it.

## Fixed

- **Writing a disc failed on every dedicated server** ("The Disc Writer changed"). The writer check
  compared a value that is computed differently on the client and the server, so it never matched off
  a single-player world. The server now uses its own check and writing works. (0.2.6)

## Changed

- **One disc is written at a time on the whole server.** If someone is already uploading, your write
  waits in a queue and starts on its own when theirs finishes, instead of both fighting for the
  server at once. You see "Someone else is uploading; you are next in the queue" while you wait.
  (0.2.7)

## Reminder

The mod has to be on the client and the server, and both have to run the same version. Update
everyone to 0.2.7.
