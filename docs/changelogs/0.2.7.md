# 0.2.7

## Changed

- Only one disc is written at a time on the whole server now. If someone is already uploading, your
  write waits in a queue and starts automatically when theirs finishes, instead of both running at
  once. You see "Someone else is uploading; you are next in the queue" while you wait.

If you run 0.2.6, updating is worth it when more than one person writes discs at the same time.
