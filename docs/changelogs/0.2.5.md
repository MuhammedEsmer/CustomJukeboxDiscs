# 0.2.5

First public release. Put your own MP3 and OGG files on music discs and play them in a vanilla
jukebox.

**What you get**

- Drop a file in `.minecraft/customjukeboxdiscs/uploads`, write it onto a Blank Disc at the Disc
  Writer, put the disc in any jukebox. Hoppers, comparators and distance falloff all behave normally
- 12 disc designs, randomly assigned, so a chest of music is not 12 identical items
- Disc Rack: a 9 slot shelf that shows the discs inside it
- Works with the Sophisticated Backpacks / Storage jukebox upgrade
- Press **J** to switch custom music off for yourself; the server then sends you nothing at all
- Server side permissions, per-player quotas, and `/customdiscs tracks` commands to moderate what
  people wrote

**Before you install**

- Needed on the client *and* the server
- Writing discs is limited to operators until you run `/customdiscs access mode everyone` or add
  people with `/customdiscs access allow <player>`
- Audio plays in mono. OpenAL will not position a stereo source, and a disc that sounds the same
  everywhere in the world is worse than one that fades properly
- Not a streaming mod: no YouTube, no Spotify, and that will not change. Optional link writing takes
  a direct `https` link to an audio file, and only from hosts the server owner allows
