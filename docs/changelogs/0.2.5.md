# 0.2.5

Nothing changes in game. This is a version bump on top of build and documentation work.

- Every push now runs the 16 in-game tests on a dedicated server, not only the unit tests, so a
  broken mixin or a client-only class reaching the server is caught before a release goes out.
- The continuous build could never start at all; the Gradle wrapper was missing its executable bit.

If you already have 0.2.4, there is no reason to update.
