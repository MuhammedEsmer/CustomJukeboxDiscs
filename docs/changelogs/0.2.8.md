# 0.2.8

## Added

- **Minecraft 26.1.2 support.** This release now has a native NeoForge 26.1.2 file for packs such as
  All the Mods 11. It contains the same disc writing, shared server library, rack, jukebox and
  playback controls as the 1.21.1 release.

## Changed

- Re-released the NeoForge 1.21.1 build under a new version after correcting its CurseForge file listing.

## Reminder

The mod has to be installed on both the client and server, and both sides must use the same version.
