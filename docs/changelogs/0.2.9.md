# Custom Jukebox Discs 0.2.9 — Minecraft 1.21.1

## Added

- Added support for optional server-side URL importer addons.
- Added compatibility with the separate Custom Jukebox Discs YouTube Addon.

## Changed

- Supported addon links work through the existing Disc Writer link field.
- Players do not need to install server-side importer addons.
- Direct audio links retain their existing server configuration and security rules.

The base mod must still be installed on both the client and server.
