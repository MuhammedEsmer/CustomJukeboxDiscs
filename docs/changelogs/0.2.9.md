# Custom Jukebox Discs 0.2.9 — Minecraft 1.21.1

## Fixed

- Newly uploaded local tracks are now added to the client cache immediately.
- Fixed newly written discs occasionally producing no sound on first playback.
- Track deletion now accepts the shortened hash shown by `/customdiscs tracks list`.
- Ambiguous shortened hashes are rejected safely without deleting a track.
- Increased the default audio source limit from 10 MB to 25 MB.
- Increased the default upload timeout from 30 seconds to 120 seconds.
- URL download timeouts now show a specific, compact error in the Disc Writer.
- Disc Writer status messages now wrap inside their available area.

## Changed

- Improved compatibility with optional server-side extensions.

The base mod must still be installed on both the client and server.
