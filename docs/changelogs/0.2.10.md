## Custom Jukebox Discs 0.2.10 — NeoForge 1.21.1

Disc Writer feedback is clearer during link imports.

### Improved

- Link imports can provide the track name automatically when the title field is empty.
- Added clear “Reading link”, download percentage and “Writing disc” stages.
- The progress bar now reflects actual transferred bytes.
- Completed writes show the final track name and retain a full progress bar.

### Fixed

- Link-based writes no longer try to cache a missing local source file.

This update adds provider-independent link import UI and API improvements. It does not add support for any specific media website.
