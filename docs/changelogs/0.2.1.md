# 0.2.1

## Fixed

- Disc Rack drew its discs on the back face instead of the front.
- Music from a backpack you carry yourself jumped between the left and right ear when walking
  sideways. Your own backpack now plays flat instead of positioned; other people's still do not.
- A link no longer has to end in `.mp3` or `.ogg`. The server decides the format from the file
  itself, so ordinary download links work.
- The link field hint and the upload status text overflowed their widgets.

## Changed

- The default list of allowed download hosts now covers the Internet Archive, Free Music Archive,
  Discord's CDN and GitHub Pages.
