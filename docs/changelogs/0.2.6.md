# 0.2.6

## Fixed

- **Writing a disc failed on every dedicated server** with "The Disc Writer changed". The server
  compared the client's writer fingerprint against its own, but that fingerprint is built from an
  item identity hash that differs between the client and server processes, so it never matched.
  Uploading worked in singleplayer only. The server now uses its own fingerprint end to end.

Anyone running 0.2.5 or earlier on a server should update; disc writing did not work there at all.
