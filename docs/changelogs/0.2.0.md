# 0.2.0

## Added

- Programmed discs now come in twelve colours, picked at random when a disc is written.
- Custom Jukebox Discs has its own creative mode tab.
- **Disc Rack**: a nine slot shelf that shows the discs it holds. Right-click a disc to take it,
  sneak or click the frame to open it like a chest. Emits a comparator signal by how full it is.
- **Turn custom music off**: press `J` (rebindable) to silence custom discs. The server then never
  sends you a track, so it costs you no bandwidth.
- **Write from a link**: with `urlUploads.enabled` the server can download a direct `https` audio
  file and validate it exactly like an upload. Operators control which hosts are allowed.
- Reworked Disc Writer screen: labelled areas, scrollable file list, progress bar, link field.

## Changed

- Jar names include the Minecraft version, for example `customjukeboxdiscs-1.21.1-0.2.0.jar`.
