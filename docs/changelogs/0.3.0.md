# Custom Jukebox Discs 0.3.0

This release brings the supported ports back to the same public version and feature baseline.

## NeoForge 1.21.1

- Accepts valid MP3 streams whose first audio frame is preceded by metadata or padding.
- Singleplayer owners can always write discs.
- New servers default to `everyone`; existing access settings are preserved.
- Keeps the Server Library cross-player write fix and improved library layout.
- Includes local cache recovery, short-hash deletion, link title/progress feedback, 25 MiB source limit and 120-second timeout defaults.

## NeoForge 26.1.2

- Adds the same MP3 detection and access-policy behavior as the 1.21.1 release.
- Ports local cache recovery and short-hash deletion.
- Fixes Server Library writes by validating the Disc Writer slot on the server.
- Adds optional link titles, named completion feedback, wrapped status text and persistent completed progress.
- Uses the same 25 MiB source limit and 120-second timeout defaults.

## Forge 1.12.2

- Adds the same MP3 detection and access-policy behavior as the NeoForge releases.
- Ports local cache recovery and short-hash deletion.
- Fixes Server Library writes by validating the Disc Writer slot on the server.
- Adds optional link titles, named completion feedback, wrapped status text and persistent completed progress.
- Uses the same 25 MiB source limit and 120-second timeout defaults.

Existing worlds keep their saved access mode. Only newly created server worlds begin in `everyone` mode.
